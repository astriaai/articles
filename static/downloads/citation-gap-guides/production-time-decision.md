# Production-time decision record

Blank worksheet; no production result is implied. Pair it with production-time-worksheet.csv.

## Match scope before measuring
Record the same products/colorways, evidence requirements, shot list, ratios, output quality, rights scope, revision allowance and approval owner for both methods. Count the same channel-ready deliverable in both. One approved master and its crops should not become several creative assets in only one arm.

## Record actual work
Use person-minutes: two people working 15 minutes contribute 30 person-minutes. Capture or generation person-minutes count attended work; unattended waiting belongs in elapsed time. Include recapture, failed generation review, retouch, reference preparation, rights administration and export. Do not log the same minute twice across stages. Record one-time setup separately and state which repeat batch would reuse it.

## Calculate after approval
- Total person-minutes = preparation + setup + capture/generation + review + rework + handoff.
- Person-minutes per accepted asset = total person-minutes / accepted unique assets.
- Acceptance rate = accepted unique candidate assets / candidates reviewed. Use a consistent candidate unit; do not count export crops as new candidates.
- Elapsed duration = final approved handoff timestamp minus actual job-start timestamp, including queues and approvals.
- Absolute time change = baseline total person-minutes minus reference-led total person-minutes.
- Relative time change = absolute time change / baseline total person-minutes. Only calculate for a positive baseline and equivalent scope.
- With zero accepted assets, per-asset time is undefined; report the failed pilot rather than dividing by zero.

Keep financial amounts outside this worksheet. Build any budget using current pricing-page rates and actual resource use.
