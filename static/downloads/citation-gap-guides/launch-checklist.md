# Product-photo launch checklist

Project / channel / owner / deadline / release owner:

## Agree review cutoffs
Record planned dates, times and timezone with each owner before production. Record actual decisions and evidence as work finishes; a planned cutoff is not a completion claim.

## Source owner: release only a complete reference set
- [ ] SKU, colorway and sample version recorded.
- [ ] Source ownership or supplier permission covers the proposed processing and use.
- [ ] Whole product, needed sides, label and construction details are sharp.
- [ ] Measurements or an actual scale photograph support any scale claims.
- [ ] Missing views are captured or removed from the brief.

## Producer: approve the smallest useful scope
- [ ] Essential PDP evidence is separated from optional campaign scenes.
- [ ] One representative product and one difficult detail are piloted.
- [ ] Source, treatment, reference IDs and job receipt saved.
- [ ] Product errors route to recapture, original-preserving retouch or rejection.

## Product reviewer: gate before creative approval
- [ ] Color, shape, pattern, closures, labels and material match the reference.
- [ ] No unverified back, underside, contents, fit or performance is implied.
- [ ] Rejected candidates remain outside the delivery folder.

## Release owner: gate before handoff
- [ ] Rights and required channel/disclosure checks completed for intended markets.
- [ ] Approved crops, filenames, alt text and accepted-output manifest match.
- [ ] Native-size, mobile and storefront checks completed.
- [ ] Unresolved product evidence uses original photography or is omitted.
- [ ] Actual completion recorded; no assumed turnaround guarantee.
