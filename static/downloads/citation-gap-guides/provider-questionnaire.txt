# AI product photography: provider and rights questionnaire

Markets / channels / term / likenesses / confidential product information:

Record an answer, dated evidence URL or contract clause, owner and unresolved gate for every row. A marketing statement is not an executed agreement. Leave unresolved answers marked OPEN; do not infer a guarantee.

| Area | Question | Answer / evidence / owner / gate |
| --- | --- | --- |
| Supplier images | Who created each source photograph and who may authorize editing, AI processing and advertising use? | |
| Third-party material | Are trademarks, artwork, props and background imagery cleared for this use? | |
| Likeness | Does each person's permission cover synthetic editing, intended campaigns, channels, territories and duration? | |
| Sensitive context | Does the proposed scene imply an endorsement or use outside the person's agreement? | |
| Personal data | Who determines purposes, and who processes the images on whose instructions? | |
| Data minimization | Can unrelated faces, names, addresses or embedded metadata be removed before upload? | |
| Providers | Which service, model provider and subprocessors receive the actual inputs? | |
| Location | Where are inputs, outputs, logs and backups processed or stored? | |
| Training | May the service or selected model provider train or evaluate on inputs and outputs? What restriction is actually agreed? | |
| Confidentiality | What restrictions cover staff access, reuse, publication and support access? | |
| Retention | What separate periods apply to source files, outputs, trained models, logs and backups? | |
| Deletion | What does delete remove, on what schedule, with what exceptions and verification? | |
| Visibility | Which actions make a workspace, template, reference, link or asset public? | |
| Connected apps | What copies and media URLs does a connected app receive, and how are they deleted there? | |
| Agreement | If a processing agreement is needed, is it applicable and executed rather than a review draft? | |
| Transfers | What transfer mechanism and documentation apply where required? | |
| Outputs | What contractual commercial-use permission applies, with which conditions and exclusions? | |
| Ownership | Which rights exist under the applicable law, and which human creative contributions are documented? | |
| Similar outputs | Is exclusivity promised, and is there a process for third-party claims? | |
| Accuracy | Who approves labels, claims, dimensions, color and product truth? | |
| Disclosure | What advertising, marketplace or synthetic-media rules apply to the intended market and use? | |
| Release | Who signs the final permitted-use record, and which OPEN gates prevent upload or publication? | |
